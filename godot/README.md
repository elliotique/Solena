# Solena — version Godot

Ouvre `project.godot` avec Godot 4.7, puis appuie sur F5.

## Contenu actuel (étape 1 : l'île)
- Une grande île de 8 km : plages, plaines, collines, montagnes enneigées au nord-ouest, désert avec mesas au sud-est, forêts, mer turquoise
- Deux villes : Solena (au centre) et Porto Sol (au sud-ouest), avec circulation, feux, piétons, commerces, parc, place et voitures garées
- Routes qui épousent le relief : autoroute A1 entre les villes, route des Cimes, route du Désert, route du Littoral, route des Vergers
- Deux aéroports aux pistes orientées différemment (30° et 125°) ; les routes arrivent côté aérogare sans jamais croiser les pistes
- Voiture : suspensions, anti-roulis, appui aérodynamique ; rendu avec illumination globale, reflets et brouillard volumétrique

## Commandes
↑↓ / W S : accélérer, freiner · ← → / A D : tourner · Espace : frein à main · R : redresser · C : caméra · T : accélérer le temps · Échap : quitter
